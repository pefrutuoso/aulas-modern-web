Hiperlinks Os hiperlinks conectam documentos, páginas, arquivos e partes específicas de uma página. Eles são uma das principais características da Web. A estrutura básica é: xml Acessar site significa âncora. href indica o destino do link. O conteúdo entre as tags é a parte clicável.
