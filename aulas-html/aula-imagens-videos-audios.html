IMAGENS A tag principal é . Ela é um elemento vazio: não possui tag de fechamento nem conteúdo interno, porque a própria tag insere a imagem no local onde aparece. Atributos principais | Atributo | Função | Exemplo | | -------- | --------------------------- | ----------------------------------- | | src | Define o caminho da imagem | src="imagens/foto.png" | | alt | Descrição textual da imagem | alt="Foto de um carro de bombeiros" | | width | Largura da imagem | width="400" | | height | Altura da imagem | height="300" | O atributo src pode usar um caminho relativo, como imagens/foto.png, ou uma URL completa, como https://site.com/foto.png. Em projetos próprios, o mais comum é manter as imagens no mesmo servidor/site que o HTML. Por que usar alt? O alt é essencial para acessibilidade. Ele é lido por leitores de tela para pessoas com deficiência visual e também aparece quando a imagem não carrega, quando o caminho está errado ou quando o usuário desativou imagens para economizar dados. Exemplo ruim: Exemplo melhor: Tamanho da imagem Você pode definir tamanho diretamente no HTML(mas não é usual, pois distorce a imagem): Ou usar CSS, que é a forma mais recomendada para separar estrutura e aparência: img { width: 400px; height: auto; } Usar height: auto ajuda a manter a proporção original da imagem quando você altera apenas a largura. Imagem com legenda Quando a imagem faz parte de um conteúdo explicativo, use figure e figcaption: O figcaption informa ao navegador e às tecnologias assistivas que aquela legenda descreve o conteúdo do figure. Formatos de imagem | Formato | Melhor uso | | ------------- | ----------------------------------------- | | .jpg ou .jpeg | Fotos com muitas cores e detalhes | | .png | Imagens com transparência, logos e ícones | | .gif | Animações simples | | .svg | Ícones, logos e ilustrações vetoriais | Imagens raster, como JPG, PNG e GIF, são formadas por pixels.
