13. Revisão e boas práticas

  • Declare o idioma e a codificação do documento.
  • Organize títulos pela hierarquia do conteúdo.
  • Use tags conforme seu significado.
  • Feche e aninhe os elementos corretamente.
  • Não coloque div, listas ou seções dentro de um p.
  • Mantenha cada id único.
  • Use classes para agrupamentos reutilizáveis.
  • Ofereça alternativas textuais para mídias.
  • Associe labels aos campos.
  • Use tabelas para dados tabulares.
  • Separe HTML, CSS e JavaScript.
  • Teste links, caminhos e controles no navegador.
  • Não guarde senhas ou segredos em comentários.
