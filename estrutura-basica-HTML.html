Principais elementos Elemento Função Indica que o documento utiliza HTML moderno. Elemento-raiz que envolve toda a página. Contém informações sobre o documento, não exibidas diretamente. Contém o conteúdo visível da página. Define o título mostrado na aba do navegador. <meta> Define informações sobre o documento. Um elemento geralmente possui tag de abertura, conteúdo e tag de fechamento: <p>Este é um parágrafo.</p> Alguns elementos são vazios, ou seja, não possuem conteúdo nem tag de fechamento: <img src="imagem.png" alt="Descrição da imagem"> Também é possível adicionar atributos: <p class="destaque">Texto importante</p> Nesse exemplo, class é o atributo e destaque é seu valor. <!-- digitando HTML:5, ja vai nos dar a estrutura básica do HTML --> <!-- RESUMO PARA MEMORIZAR --> HTML → estrutura e significado <head> → metadados e configurações <body> → conteúdo visível <meta> → informações sobre o documento <title> → título da aba <h1>-<h6> → hierarquia de títulos <p> → parágrafo <ul> → lista não ordenada <ol> → lista ordenada <li> → item de lista <a> → hiperlink href → destino do link <em> → ênfase <strong> → importância <img> → imagem alt → descrição alternativa da imagem <div> → agrupamento em bloco sem semântica <span> → agrupamento inline sem semântica
